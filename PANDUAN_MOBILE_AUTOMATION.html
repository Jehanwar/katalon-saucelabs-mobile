1. Arsitektur Lightweight Real Device

Dibandingkan menggunakan emulator Android Studio yang memakan RAM hingga 8GB-12GB dan memperlambat laptop, arsitektur Real Device jauh lebih ringan, stabil, dan merepresentasikan pengalaman pengguna nyata.

Alur Komunikasi:
Katalon Studio (Script Groovy) ➔ Appium Server 2.x (Port Dinamis / 4723) ➔ UiAutomator2 Server (di dalam HP) ➔ Aplikasi Swag Labs.

2. Matriks Versi yang Kompatibel (Sangat Kritis)

⚠️ Peringatan Kompatibilitas Versi:
Kesalahan umum nomor 1 pada Appium 2.x adalah menginstal driver tanpa tag versi. Menginstal driver uiautomator2 versi terbaru (4.x/5.x) akan gagal karena versi tersebut khusus untuk Appium 3 RC. Untuk Appium 2.x, WAJIB menggunakan uiautomator2@3.8.0.

3. Langkah Setup Lengkap dari Nol

A. Terminal Setup

# 1. Install Appium secara global
npm install -g appium

# 2. Install Driver uiautomator2 versi kompatibel
appium driver install uiautomator2@3.8.0

# 3. Cek apakah terpasang
appium driver list

B. Setup HP Android

  1. Masuk ke Pengaturan ➔ Tentang Ponsel ➔ Informasi Perangkat Lunak ➔ Ketuk Nomor Versi (Build Number) sebanyak 7 kali.
  2. Buka Pilihan Pengembang (Developer Options) ➔ Aktifkan Debugging USB (USB Debugging).
  3. Aktifkan opsi Tetap Terjaga (Stay Awake) agar layar tidak terkunci selama dicolok USB.
  4. Hubungkan kabel USB ke laptop, setujui dialog "Selalu izinkan dari komputer ini".

C. Konfigurasi di Katalon Studio

  1. Appium Directory: Menu Window ➔ Preferences ➔ Katalon ➔ Mobile ➔ Arahkan ke:
    C:\Users\<username>\AppData\Roaming\npm\node_modules\appium
  2. Anti-Crash SplashActivity: Menu Project ➔ Settings ➔ Desired Capabilities ➔ Mobile ➔ Android ➔ Tambahkan properti:
    Name: appWaitActivity, Value: *

4. Implementasi Test Case & Standar Rubrik

  • No Hardcode Path: APK disimpan di dalam folder proyek androidapp/SauceLabs.apk dan dipanggil menggunakan:
    String appPath = RunConfiguration.getProjectDir() + '/androidapp/SauceLabs.apk'

5. Kamus Troubleshooting & Solusi Cepat

1. Error "Fail to start Appium server in 30 seconds"
Penyebab: Sesi Mobile Object Spy atau proses node lama menggantung di background.
Solusi: Tutup jendela Spy, jalankan di PowerShell: Stop-Process -Name "node" -Force.
2. Status Langsung <Done> (0/1 Runs) tanpa Reaksi di HP
Penyebab: Script memiliki garis merah error di editor (misal: GlobalVariable belum sinkron).
Solusi: Tutup tab default profile, lalu klik menu Project ➔ Refresh (F5) dan Project ➔ Clean....
3. HP Diam / Timeout Mengetik
Penyebab: Layar HP mati masuk mode Dozing/Terkunci.
Solusi: Buka kunci layar HP dan aktifkan Stay Awake di Developer Options.
